# Test Case N1
## Покупка последнего доступного товара с двух разных аккаунтов

## Description
Проверка обработки транзакции, когда два разных пользователя одновременно пытаются купить последнюю доступную единицу одного и того же товара.

## Precondition
- **Пользователь A** и **Пользователь B** авторизованы в системе  
- У обоих пользователей в корзине находится один и тот же товар:  
  - Название товара: Samsonite - RESTACKD 81/30  
  - Количество товара на складе = 1  

## Post-condition
- **Пользователь A** успешно оформляет заказ  
- **Пользователь B** не может купить товар и получает сообщение об ошибке: **«Товар отсутствует на складе»**  
- Количество товара на складе в системе = 0  

## Single parameters

| Parameter | Details |
|--------------------------------|------------------------------------------------------|
| **Пользователь A - Аккаунт** | testUser1@gmail.com, Test123! |
| **Пользователь B - Аккаунт** | testUser2@gmail.com, Test123! |
| **Пользователь A - Данные карты** | Номер карты: 4111 1111 1111 1111<br>Срок действия: 12/26<br>CVV: 123 |
